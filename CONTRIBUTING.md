## 💚 Obrigada por querer contribuir!

Toda contribuição — grande ou pequena, técnica ou pedagógica — é bem-vinda na comunidade **Bio+Tech EduDesign**. Este guia foi feito para tornar sua jornada de contribuição **clara, acolhedora e produtiva**.

> **Antes de tudo:** leia nosso [Código de Conduta](CODE_OF_CONDUCT.md). Toda contribuição está sujeita a ele. 🌱

---

## 🎯 Tipos de contribuição aceitas

| Tipo | Exemplos |
|:---|:---|
| 🐛 **Correção de bug** | Erros em código, links quebrados, imagens que não carregam |
| ✨ **Nova funcionalidade** | Novo OAD, nova trilha gamificada, novo template |
| 📚 **Conteúdo pedagógico** | Revisão científica, adaptação para nível escolar, exemplos |
| 🎨 **Design e acessibilidade** | Melhorias visuais, alt-text, contraste, legibilidade |
| 📝 **Documentação** | Correções ortográficas, tutoriais, tradução |
| 🧪 **Testes** | Aplicação em sala de aula com retorno documentado |

## 🚀 Fluxo de contribuição (passo a passo)

### 1️⃣  Antes de começar

- 🔍 Verifique se **já não existe uma issue** aberta sobre o tema em [Issues](../../issues).
- 💬 Se tiver dúvidas, abra uma [Discussão](../../discussions) primeiro.
- ✅ Para mudanças grandes, abra uma issue **antes** de codar — assim alinhamos escopo.

### 2️⃣  Preparando o ambiente

```bash
# 1. Faça um fork do repositório no GitHub
# 2. Clone o seu fork
git clone https://github.com/SEU-USUARIO/NOME-DO-REPO.git
cd NOME-DO-REPO

# 3. Adicione o repositório original como upstream
git remote add upstream https://github.com/Bio-Tech-Edu/NOME-DO-REPO.git

# 4. Crie uma branch descritiva
git checkout -b feat/nome-da-sua-contribuicao
